* **Test Design & Execution:** Positive/Negative testing, Boundary Value Analysis, Atomic Test Case structuring.
* **Requirements Management:** Mapping functional requirements (`REQ`) to test coverage via Traceability Matrices.
* **Risk & Security Awareness:** Identifying authentication vulnerabilities, input sanitization gaps, and account lifecycle edge cases.
